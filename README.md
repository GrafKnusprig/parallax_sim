# Gaia3 Data Subset for Unity

This project requires the Gaia3 data subset, available at:
https://www.kaggle.com/datasets/philippraven/gaia3-data-subset-optimized-for-use-in-unity

## Setup Instructions

1. **Download the Dataset**
   - Download the dataset from the Kaggle link above.

2. **Place in StreamingAssets**
   - Move the downloaded dataset into the `Assets/StreamingAssets` folder of your Unity project.

3. **Configure Path in SolarSystemParallaxManager**
   - In your code, ensure that the relative path to the dataset is set in the `SolarSystemParallaxManager` script.
